#   3D Printable STL making (With AI Assistance)
To be complete real i never owned a 3d printer also i am quite a begineer at amking models so i have used ai to make my model 3d printable and Helped in----
1. **Solidified the grills:** Converted the 2D wireframe planes into 3.5mm solid cylindrical bars so the 3D printer nozzle can actually print them without breaking.
2. **Fused all 41 parts:** Welded all separate overlapping objects into one single, continuous, watertight shell with 0 non-manifold edges.
3. **Scaled & bed leveled:** Scaled the model to an exact 100mm miniature height and flattened the base flat at Z = 0.0 mm for immediate bed adhesion without needing rafts.
![stl rendered](./journal%20media/image%20(28).png)

4. **Slicing setup:** Configured for 15% Gyroid infill (keeps it lightweight, using ~55g PLA filament for ~$1.10) with tree supports under the porch and awning.
